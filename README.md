# Справочник городского транспорта

Учебный проект по дисциплине «Конструирование программного обеспечения».
Стек: Go, PostgreSQL и React. Лабораторная №5 посвящена управлению исходным кодом,
автоматическим проверкам, сборке и метрикам качества.

Задачи и график: [YouTrack SGT](https://vasmaae.youtrack.cloud/issues/SGT).
Предыдущие отчёты находятся в `reports/`.
