# Прототип справочника SGT

Задача: [SGT-14](https://vasmaae.youtrack.cloud/issue/SGT-14).
Прототип проверяет связность страниц и достаточность модели маршрутов, направлений
и остановок. Сценарии основаны на SGT-3, SGT-4, SGT-5, SGT-6 и SGT-7.

1. В каталоге найти автобус №1 по номеру и виду транспорта.
2. Открыть маршрут: Вокзал → Площадь Мира (северная сторона) → Университет.
3. Переключить направление: Университет → Площадь Мира (южная сторона) → Вокзал.
4. Открыть остановку «Площадь Мира», убедиться, что показано именно обратное
   направление, и вернуться по ссылке к маршруту.
5. В каталоге остановок поиск «мИрА» показывает две одноимённые остановки с
   разным расположением; поиск без совпадений показывает пустое состояние.

Прототип использует PostgreSQL, Go и React и работает с клавиатуры. Данные вымышлены.
Расписание и администрирование входят в последующие этапы. Прототип показал,
что обратное направление нельзя автоматически считать обращением прямого,
а остановку нужно идентифицировать по ID, а не по названию. Эти решения
перенесены в модель итоговой системы. Оценки ЛР2–3 сохраняются для сравнения;
согласование с преподавателем проводится на защите.
