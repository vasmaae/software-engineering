# Порядок работы с отчётами

Отчёты лабораторных работ в `reports/` сначала готовятся локально и показываются
пользователю. Включать конкретную версию отчёта в коммит или PR и отправлять её
на GitHub можно только после явного одобрения этой версии пользователем.

Имена веток и остальные правила работы описаны в `docs/contributing.md`.
